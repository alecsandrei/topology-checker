Function explode_lines

pub fn explode_lines(
    lines: impl IntoIterator<Item = LineString>,
) -> Result<Vec<LineString>, Error>
Expand description

Explode nondegenerate parts into individual segments, preserving duplicate uses. Consecutive duplicate coordinates are removed; remaining segments retain input part order and direction. Output coordinates use the original planar units and carry no feature provenance.

§Errors

Returns Error::NonFiniteLine for non-finite input coordinates.
