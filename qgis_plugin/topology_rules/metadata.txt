description=Check vector layers for topology errors such as dangles, gaps, overlaps and duplicate points
about=Topology Rules adds the rules of topology-checker to the Processing toolbox and to a dock panel, where several rules can be queued, run in one pass and browsed by the errors found. The rules cover points, lines and polygons, on one layer or two. Errors are added to the project as layers. The checks need one of two external dependencies, which the plugin does not include. The Python package topology-checker from PyPI, for Python 3.10 or newer with shapely 2 and pyproj 3.4: choose Install Python package in the panel menu, which shows the wheel and its SHA-256 before downloading it, or run "python -m pip install --no-deps --target <folder> topology-checker==<version>" with the Python of QGIS, in the OSGeo4W Shell on Windows or a terminal on macOS and Linux; the panel shows the exact command. Installs nothing else; uses the shapely and pyproj that come with QGIS. Or the command line tool topology-checker 0.2.0 or newer: "cargo install topology-checker --locked" or a release from the repository, chosen in the panel, set under Settings > Options > Processing > Providers > Topology Rules, or on the PATH.
