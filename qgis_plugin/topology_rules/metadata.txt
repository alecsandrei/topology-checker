description=Check vector layers for topology errors such as dangles, gaps, overlaps and duplicate points
about=Topology Rules adds the rules of the topology-checker command line tool to the Processing toolbox and to a dock panel, where several rules can be queued, run in one pass and browsed by the errors found. The rules cover points, lines and polygons, on one layer or two. Errors are added to the project as layers. The plugin does not include the tool: install topology-checker 0.2.0 or newer with "cargo install topology-checker --locked" or download a release from the repository, then choose it in the panel, set its path under Settings > Options > Processing > Providers > Topology Rules, or put it on the PATH.
