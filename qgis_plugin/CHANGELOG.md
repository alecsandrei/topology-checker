# Changelog

## 0.3.0

* Choose the engine and install the Python package from the panel's gear menu.
* Choose how errors are drawn from Style in the gear menu: colour by, size and colour ramp.
* Find the executable that `cargo install` put in Cargo's bin folder, and show its path in the gear menu.
* Show each rule's results as soon as the rule is done, and keep them when a run is canceled.
* Open large groups of errors in the Errors tab at once.
