Python API¶

Native planar topology checks for Python GIS workflows.

Topology ¶

Topology(tolerance: float = 0.0)

Own planar layers, ordered rules, and reusable native topology caches.

Parameters:

Name Type Description Default
tolerance float

Nonnegative finite distance in input coordinate units.

 0.0

Raises:

Type Description
ValueError

Tolerance is negative or nonfinite.

tolerance property ¶

tolerance: float

Return the planar tolerance in caller-supplied coordinate units.

layers property ¶

layers: tuple[Layer, ...]

Return immutable layer snapshots in registration order.

layer ¶

layer(id: LayerId) -> Layer

Return a registered layer, rejecting IDs from other topologies.

add_layer ¶

add_layer(data: Any, *, name: str | None = None, fids: Iterable[int] | None = None, crs: Any = None, kind: GeometryKind | None = None) -> LayerId

Snapshot and register GIS data as a planar layer.

Parameters:

Name Type Description Default
data Any

Geometry iterable, GeoSeries, GeoDataFrame, GeoJSON mapping, or object implementing geo_interface.

 required
name str | None

Optional display label. Defaults to layer_N using registration order.

 None
fids Iterable[int] | None

Unique signed 64-bit IDs for all original input positions.

 None
crs Any

Optional CRS, which must agree with input and known layer metadata.

 None
kind GeometryKind | None

Optional POINT, LINE, or POLYGON declaration for ambiguous data.

 None

Returns:

Type Description
LayerId

An identity scoped to this topology.

Raises:

Type Description
TypeError

Input data, the name, or the declaration has an unsupported type.
ValueError

Coordinates, FIDs, geometry, or CRS metadata are invalid.
RuntimeError

An input callback tries to register on this topology.

add_rule ¶

add_rule(rule: Rule, data: Any, *, other: Any = None) -> RuleSpec

Snapshot raw GIS inputs or reuse IDs, then atomically register a rule.

Each raw input creates a fresh snapshot. Pass a LayerId to reuse a layer.

Parameters:

Name Type Description Default
rule Rule

Rule member. Deserialize strings explicitly with Rule(value).

 required
data Any

Primary GIS input or a LayerId from this topology.

 required
other Any

Optional secondary GIS input or distinct registered LayerId.

 None

Returns:

Type Description
RuleSpec

The immutable specification, including reusable IDs and native semantics.

Raises:

Type Description
TypeError

The rule or input has an unsupported type.
ValueError

IDs, families, arity, coordinates, FIDs, or CRS are invalid. Failed calls leave registrations and visible warnings unchanged.
RuntimeError

An input callback tries to register on this topology.

warnings ¶

warnings() -> tuple[str, ...]

Return input, degenerate-part, and combined CRS warnings.

iter_validate ¶

iter_validate(batch_size: int = 1024) -> ValidationStream

Stream a snapshot in bounded binary batches, closing it on early exit.

Parameters:

Name Type Description Default
batch_size int

Positive maximum number of buffered violations.

 1024

Returns:

Type Description
ValidationStream

A closeable iterator, with final summary after exhaustion.

validate() -> Report

Run native validation and return an eager immutable report.

ValidationStream ¶

ValidationStream(native: NativeValidationStream, layers: tuple[Layer, ...], specs: tuple[RuleSpec, ...], warnings: tuple[str, ...], crs: CRS | None)

Bases: Iterator[Violation]

Yield aggregated violations in deterministic rule and feature order.

Use a context manager or close() when stopping early. The worker owns immutable snapshots; later registrations cannot change this stream. Final summary is available only after successful exhaustion, and is None after early close.
