# Natural Earth example data

Made with Natural Earth. The five source snapshots and the two grouped datasets
in this directory are public-domain map data. Natural Earth permits use,
modification and redistribution for personal, educational and commercial use.

Terms: https://www.naturalearthdata.com/about/terms-of-use/
Source: https://github.com/nvkelso/natural-earth-vector/tree/ca96624a56bd078437bca8184e78163e5039ad19/geojson

The source snapshots are unchanged downloads. The grouped datasets preserve the
original coordinates and attributes; they add country-code grouping and member
references. Data accuracy and suitability depend on the intended use. This data
notice is separate from the application's software license.
